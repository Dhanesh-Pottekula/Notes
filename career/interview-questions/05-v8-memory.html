Interview questions · 05

V8 engine and memory

270 questions · L1 74 · L2 133 · L3 63 · 13 sub-topics

Product companies that run Node.js at scale ask "how does your code actually run?" — how V8 compiles and optimizes it, how memory is laid out, how the GC works, and above all how you found and fixed a memory leak in production. A 3-year engineer must explain the pipeline, hidden classes, GC generations and the leak-hunting workflow without notes, and know how this differs from Python's memory model. Syllabus: 1A V8 Engine & Memory (../../syllabus.html).
