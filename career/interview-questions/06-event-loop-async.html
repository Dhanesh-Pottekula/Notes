313 questions · L1 82 · L2 163 · L3 68 · 16 sub-topics

"Is Node single-threaded?", "predict the output", "how do you handle CPU-heavy work?" and "what is backpressure?" come up in almost every Node.js round. A 3-year backend engineer must draw the event loop phases, explain the microtask queues and the libuv thread pool, spot a blocked loop in production, and build a stream pipeline that handles a 10 GB file in constant memory.
