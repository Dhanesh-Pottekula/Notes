JavaScript and TypeScript

381 questions · L1 106 · L2 202 · L3 73 · 20 sub-topics

Every Node.js/NestJS round starts with JavaScript fundamentals (coercion, closures, this, prototypes, "implement debounce") and, for TypeScript shops, moves to the type system: narrowing, generics, conditional and mapped types, and "how would you type this API?". A 3-year engineer must answer the JS core instantly, write small polyfills on a whiteboard, and use TypeScript to model a domain (branded ids, discriminated unions, Result types), not just annotate it. Syllabus: 1C TypeScript Deep Mastery (../../syllabus.html).
