Interview questions · 08

Testing

249 questions · L1 65 · L2 125 · L3 59 · 14 sub-topics

Testing questions show up in coding rounds ("now write tests for it"), in backend rounds ("how do you test code that calls an LLM?") and in culture-fit rounds ("how do you keep quality up with a small team?"). A 3-year engineer must explain what to test and why, pick the right kind of test double, and show a real test setup for an API, a database, async code and an LLM feature. Syllabus: 1D Testing (../../syllabus.html).
