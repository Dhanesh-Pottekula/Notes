13.1 Inference basics — prefill, decode and the KV cache

Learn: AIE ch9 "Inference Overview" (pdf p430–435, compute-bound vs memory-bound) · HOL ch3 "Speeding Up Generation by Caching Keys and Values" (pdf p105) · LEH ch8 "KV cache" (pdf p320–322) · kipp.ly/transformer-inference-arithmetic/

  • L1 What does "inference" mean for an LLM, as opposed to training?
  • L1 What is autoregressive generation? Why must tokens be produced one at a time?
  • L1 What are the two phases of LLM inference?
    prefill (whole prompt in parallel) then decode (one token per step)
  • L1 What is the KV cache?
  • L1 Why is output (generated) text slower and more expensive than input text?
  • L2 Why is prefill compute-bound and decode memory-bandwidth-bound?
    prefill = big matrix-matrix; decode = reread all weights per token
  • L2 What would happen to generation speed without a KV cache?
    recompute keys/values for every past token each step; quadratic work
  • L2 Why does the first token take longer than the following ones?
  • L2 What does the KV cache store exactly, per token and per layer?
    key and value vectors for every layer and KV head
  • L2 Write the KV cache size formula.
    2 × layers × kv_heads × head_dim × bytes × tokens × batch
  • L2 KV cache per token for a Llama-2-7B-shaped model (32 layers, 4096 hidden, fp16)?
    2×32×4096×2 B ≈ 0.5 MB per token
  • L2 Why does long context need so much GPU memory even when the model weights fit?
  • L2 What is arithmetic intensity, and why does batching raise it during decode?
  • L2 Rough upper bound for single-stream decode speed of a 7B fp16 model on a GPU with 2 TB/s bandwidth?
    ~2000 GB/s ÷ 14 GB ≈ 140 tokens/s
  • L2 What does max_tokens / max_new_tokens do to latency and memory reservation?
  • L3 How do multi-query attention (MQA) and grouped-query attention (GQA) shrink the KV cache?
    fewer KV heads shared across query heads
  • L3 Recompute the KV-per-token number for Llama-3-8B with GQA (8 KV heads, head_dim 128).
    2×32×8×128×2 B = 128 KB per token
  • L3 What is KV cache quantization (fp8/int8 KV), and what does it cost in quality?
  • L3 What is KV cache offloading to CPU RAM or disk, and when is it worth it?
  • L3 What is sliding-window attention and how does it bound KV cache growth?
  • L3 Why does a 128k-context request hurt every other request on the same GPU?
