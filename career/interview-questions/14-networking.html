Networking fundamentals

415 questions · L1 111 · L2 198 · L3 106 · 16 sub-topics

Networking shows up in every backend loop: "what happens when you type a URL", TCP vs UDP, TLS, HTTP versions, and "the service is timing out — debug it". A 3-year engineer must explain each layer a request crosses, read curl -v and ss output, and reason about timeouts, retries and long-lived connections (your AiRA voice WebSocket is the best story here). Syllabus: 2F Networking (../../syllabus.html).
