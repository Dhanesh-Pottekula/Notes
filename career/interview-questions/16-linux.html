Linux for backend engineers

350 questions · L1 101 · L2 177 · L3 72 · 17 sub-topics

Linux questions check whether you can run and debug your own services: "a server is slow — what do you run first?", "port 8080 is in use", "SIGTERM vs SIGKILL", "too many open files". A 3-year engineer who has run Docker on Azure/AWS VMs must read top, free and ss output, explain processes, signals and file descriptors, and write a safe shell script. Syllabus: 3B Linux (../../syllabus.html).
