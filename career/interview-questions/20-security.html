Security — OWASP, auth, crypto, secrets, supply chain, LLM agents

473 questions · L1 108 · L2 253 · L3 112 · 28 sub-topics

Security questions show up in backend rounds as "how would an attacker break this endpoint?" and in senior rounds as "how did you protect user secrets?". A 3-year engineer must name the attack, explain why it works, and give the fix in code — and, for an AI engineer, defend an agent against prompt injection.
