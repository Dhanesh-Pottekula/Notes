Core CS — operating systems, concurrency, DBMS theory, computer networks basics

328 questions · L1 121 · L2 157 · L3 50 · 16 sub-topics

Service companies and many product companies run one rapid-fire theory round on OS, DBMS and networks, and startups drill the concurrency parts because they show up in real bugs. A 3-year engineer must answer the definitions instantly, write a correct producer–consumer and the classic SQL queries, and link the theory to backend work (event loops, connection pools, isolation levels). Networks are kept short here; a separate networking file goes deeper. Topic checklist: ../interview-topics/09-core-cs.md.
