Cloud — Azure, AWS and GCP

295 questions · L1 89 · L2 164 · L3 42 · 16 sub-topics

Azure and AWS are on the resume, so expect "how did you run it on Azure, and how would it look on AWS?". A 3-year engineer must pick compute, networking, storage and identity services with reasons, keep secrets out of code with managed identities and a vault, and know what drives the bill. Not a syllabus section; it backs the resume line.
