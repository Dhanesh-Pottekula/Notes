How to use it

  • Levels: L1 = fundamentals, answer instantly · L2 = the standard 3-year question · L3 = deep follow-up, internals, failure modes, design at scale. Inside a sub-topic the questions go L1 → L2 → L3, the way an interviewer drills down.
  • A grey line under a question (after ↳) names what a good answer must contain — it is a hint, not the answer.
  • Tick a question when you can answer it out loud in about 2 minutes without notes. Ticks are saved in this browser and show on both the topic page and the all-questions page.
  • Open the pages through python3 Notes/serve_notes.py (127.0.0.1:8780/career/interview-questions/) so highlights and margin notes save.
  • Pair with the topic checklists and sources in interview-topics.
  • Edit the .md files, then run python3 Notes/career/interview-questions/build.py. The format is in FORMAT.md.
