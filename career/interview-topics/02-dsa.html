Data structures and algorithms (P0)

Target for 3 years: LeetCode mediums in ≤25 min, explain the brute force first, then optimise, state time and space Big-O, and dry-run on an example. Do NC150 in order (about 2 problems a day ≈ 12 weeks), then redo the ones you failed.

How to practise each problem: 5 min think → code → test edge cases (empty, one element, duplicates, negatives, overflow) → say complexity. If stuck at 25 min, watch the NeetCode video, then redo it 3 days later.

Learn (all sections): NC150 (neetcode.io, free videos) · LC · Grokking the Coding Interview patterns (free summaries online) · visualgo.net for trees/graphs/heaps.
