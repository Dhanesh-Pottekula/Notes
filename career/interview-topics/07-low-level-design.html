Low-level design and OOP — machine coding (P1)

Format: 60–90 minutes, build a working, extensible program (in-memory, no DB) with clean classes, then extend it when the interviewer adds a requirement. They judge: class design, naming, SOLID, patterns, tests, and how easily the new requirement fits.

7.6 Practical backend coding round (very common at startups)

Format: 60–120 min, build a small working service, often with an existing repo. Practise these until each takes ≤60 min:

  • CRUD REST API with validation, pagination, filtering and error handling (FastAPI and NestJS)
    fastapi.tiangolo.com/tutorial/ (Query Params, Handling Errors) · docs.nestjs.com/techniques/validation · docs.stripe.com/api/pagination
  • Add JWT auth + role checks to an existing API
    fastapi.tiangolo.com/tutorial/security/oauth2-jwt/ · docs.nestjs.com/security/authentication · docs.nestjs.com/security/authorization
  • Add a background job (queue + worker) with retries
    docs.bullmq.io/guide/retrying-failing-jobs · docs.nestjs.com/techniques/queues · aws.amazon.com/builders-library/timeouts-retries-and-backoff-with-jitter/
  • Add caching with Redis and invalidation on write
    aws.amazon.com/caching/best-practices/ · docs.nestjs.com/techniques/caching · hellointerview.com/learn/system-design/core-concepts/caching
  • Add rate limiting middleware
    docs.nestjs.com/security/rate-limiting · stripe.com/blog/rate-limiters
  • Write unit + integration tests for what you built
    fastapi.tiangolo.com/tutorial/testing/ · docs.nestjs.com/fundamentals/testing · testcontainers.com
  • Integrate an LLM call: structured output, timeout, retry, streaming endpoint (SSE)
    platform.openai.com/docs/guides/structured-outputs · fastapi.tiangolo.com/advanced/custom-response/ (StreamingResponse) · developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events
  • Take-home hygiene: README, run instructions, .env.example, docker compose, clear commits
    makeareadme.com · docs.docker.com/compose/ · 12factor.net/config

Questions: "Build a URL shortener API with analytics in 60 minutes" · "Build an endpoint that summarises an uploaded PDF with an LLM and streams the result" · "Here is a slow endpoint — make it fast"
